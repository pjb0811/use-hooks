# Timing

Debounce, throttle, animation-frame, and interval/timeout scheduling, with
proper cleanup on unmount.

<DemoTheme>

## useDebouncedCallback {/* #use-debounced-callback */}

<DebouncedCallbackDemo />

```tsx
const [text, setText] = useState('');
const [debounced, setDebounced] = useState('');

useDebouncedCallback(() => setDebounced(text), { delay: 400 }, [text]);
```

The returned function also acts on a call that is still waiting: `flush()` runs it now and `cancel()` drops it. Both do nothing when no call is waiting. By default a waiting call is dropped when the component unmounts; pass `flushOnUnmount: true` to run it instead, for work that must not be lost when its UI goes away.

```tsx
const save = useDebouncedCallback(
  () => persist(draft),
  { delay: 1000, flushOnUnmount: true },
  [draft],
);

<textarea
  value={draft}
  onChange={e => setDraft(e.target.value)}
  onBlur={save.flush}
/>;
```

## useTimeout {/* #use-timeout */}

<TimeoutDemo />

```tsx
const [open, setOpen] = useState(false);
const { reset, clear } = useTimeout(() => setOpen(false), open ? 2000 : null);

// Pause the auto-dismiss while hovered, restart it on mouse leave
<div onMouseEnter={clear} onMouseLeave={reset}>
  Toast
</div>;
```

## useAnimationFrameCallback {/* #use-animation-frame-callback */}

<AnimationFrameCallbackDemo />

```tsx
const [schedule, cancel] = useAnimationFrameCallback(
  (x: number, y: number) => setPosition({ x, y }),
  { window: targetWindow }, // optional, defaults to the global window
);

window.addEventListener('scroll', () =>
  schedule(window.scrollX, window.scrollY),
);
```

`schedule(...args)` requests a frame if none is pending. More calls before it
fires replace the arguments, so the callback runs once per frame with the latest
ones. `cancel()` drops the pending frame, and unmounting cancels it too.
`schedule` and `cancel` keep their identity across renders, and the callback may
call `schedule` again to repeat on every frame. The `window` option uses another
window's `requestAnimationFrame`, for elements that live in an iframe.
