# Events & Interaction

Hooks for DOM events, page visibility, keyboard shortcuts, click-outside
detection, and drag-and-drop file handling.


## useIdle {/* #use-idle */}

<IdleDemo />

```tsx
const idle = useIdle(60_000);

useEffect(() => {
  if (idle) {
    saveDraft();
  }
}, [idle]);
```

Activity is `pointermove`, `pointerdown`, `keydown`, `wheel` or `touchstart`
on `window` (change it with `events`), or the page becoming visible again.
Activity only restarts the timer while the user is active, so it doesn't
render the component again. Pass `initialState: true` to start as idle.

## useOnlineStatus {/* #use-online-status */}

<OnlineStatusDemo />

```tsx
const online = useOnlineStatus();

<Button disabled={!online}>Save</Button>;
```

`true` means the browser is connected to a network, not that a given server
is reachable. On the server it is `true`.

## useHoverOrFocusWithin {/* #use-hover-or-focus-within */}

<HoverOrFocusWithinDemo />

```tsx
const { active, hovered, focusWithin, handlers } = useHoverOrFocusWithin({
  enabled: pauseOnHover,
  onActiveChange: active => (active ? clear() : reset()),
});

<div {...handlers}>{children}</div>;
```

`hovered` follows `onMouseEnter` and `onMouseLeave`, and `focusWithin` follows
`onFocus` and `onBlur`. A `blur` whose `relatedTarget` is still inside the
container is ignored, so moving focus between two children does not change
anything. `active` is `hovered || focusWithin`. With `enabled: false`,
`handlers` is empty and every flag is `false`.

## useClickOutside {/* #use-click-outside */}

<ClickOutsideDemo />

```tsx
const [open, setOpen] = useState(false);
const triggerRef = useRef<HTMLButtonElement>(null);
const panelRef = useRef<HTMLDivElement>(null);

// Both the trigger and the panel are "inside" — otherwise clicking the
// trigger to close it would register as an outside click and reopen it.
// escape defaults to false as of v4 — pass it explicitly to close on Escape too.
useClickOutside([triggerRef, panelRef], () => setOpen(false), {
  enabled: open,
  escape: true,
});

<button ref={triggerRef}>Toggle</button>;
{
  open && <div ref={panelRef}>Panel</div>;
}
```

## useLongPress {/* #use-long-press */}

<LongPressDemo />

```tsx
const { handlers, isLongPressed } = useLongPress(() => openMenu(), {
  threshold: 500,
  keyboard: true,
});

<button {...handlers} onClick={() => !isLongPressed() && select()} />;
```

Pointer events cover mouse, touch and pen, and only the primary button starts
a press. Releasing, leaving, a `pointercancel` or moving more than
`moveTolerance` px (default 10) cancels it, and `onCancel` is called.
`isLongPressed()` stays `true` from the long press until the task after the
release, so a click handler can skip the click that ends it, and a later click
(from the keyboard, for example) reads `false`. On a `<button>`,
Enter fires `click` on keydown, before the long press, so only Space can be
told apart that way. `handlers` keeps its identity while `enabled` and
`keyboard` stay the same.
