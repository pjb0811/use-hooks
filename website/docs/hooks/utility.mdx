## useCopyToClipboard {/* #use-copy-to-clipboard */}

<CopyToClipboardDemo />

```tsx
const { copy, copied, error } = useCopyToClipboard({ resetDelay: 1500 });

const ok = await copy('pnpm add @jbpark/use-hooks'); // true on success, false on failure
```

`copied` is `true` for `resetDelay` ms after a successful copy (default 1500),
and each copy restarts that time. Pass `resetDelay: null` to keep it `true`
until the next copy. `error` holds the last failure, such as a missing
Clipboard API or a denied permission, until the next successful copy.

## useLatest {/* #use-latest */}

<LatestDemo />

```tsx
const onTickRef = useLatest(onTick);

useEffect(() => {
  const id = setInterval(() => onTickRef.current(), 1000);

  return () => clearInterval(id);
}, [onTickRef]);
```

`current` is updated in an effect after each render, so read it from event
handlers, timers and effects, not during render. An effect that runs earlier in
the same commit can still see the previous value. The returned ref keeps one
identity, so it is safe in a dependency array.
