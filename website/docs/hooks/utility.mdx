
## useLatest {/* #use-latest */}

<LatestDemo />

```tsx
const onTickRef = useLatest(onTick);

useEffect(() => {
  const id = setInterval(() => onTickRef.current(), 1000);

  return () => clearInterval(id);
}, [onTickRef]);
```

`current` is updated in an effect after each render, so read it from event
handlers, timers and effects, not during render. An effect that runs earlier in
the same commit can still see the previous value. The returned ref keeps one
identity, so it is safe in a dependency array.
